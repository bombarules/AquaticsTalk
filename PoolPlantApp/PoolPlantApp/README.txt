Pool Plant app (WebView wrapper)
1. Install Android Studio, then File > Open this folder.
2. Let Gradle sync (needs internet once).
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK: app/build/outputs/apk/debug/app-debug.apk
5. Copy to the phone, open it, allow "install unknown apps" for your file manager.
Pages live in app/src/main/assets/. The 3D page loads three.js from the internet.
