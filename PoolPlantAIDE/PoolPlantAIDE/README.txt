POOL PLANT - AIDE project (no Gradle)

1. Unzip. You get one folder: PoolPlantAIDE
2. Move it to /storage/emulated/0/AppProjects/PoolPlantAIDE
   The path must have NO spaces (do not use "Pool New").
3. In AIDE: tap the folder icon > open the PoolPlantAIDE folder
   (the folder that directly contains AndroidManifest.xml).
4. Tap the Play button to build and install.

The 3D page loads its 3D library from the internet, so it needs a connection.
